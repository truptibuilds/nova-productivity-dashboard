# NOVA — Personal Productivity Dashboard

A modern and responsive personal productivity dashboard built with HTML, CSS, and JavaScript.

NOVA brings everyday productivity features into one clean interface, including task management, productivity statistics, weather information, theme customization, and live date/time updates.

## ✨ Features

- 📝 Add, complete, and delete tasks
- 📊 Productivity statistics and task breakdown
- 📈 Interactive productivity chart
- 🌤️ Weather information using an API
- 🕐 Live clock and date
- 👋 Dynamic greeting
- 💬 Daily motivational quotes
- 🌙 Dark and light theme
- 💾 Task persistence using Local Storage
- 📱 Responsive design for different screen sizes
- 🧭 Multi-section dashboard navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Open-Meteo API
- Local Storage
- Git & GitHub
